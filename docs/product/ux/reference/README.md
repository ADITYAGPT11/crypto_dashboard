# Reference designs

Static images of planned screens, rendered at 1440 px from the design canvas
[TCS Planned Screens](https://claude.ai/artifact/UipGn8QUBAKm1A22qL1K8b) (private to the owner;
the canvas is where ideas and comments are added). All numbers are **sample data**, shaped like
the real engine output (n, Wilson 95% range, break-even). When the canvas changes, re-render and
replace the image so this folder always matches the latest agreed design.

| Screen                         | Image                                                      | Status                                                    |
| ------------------------------ | ---------------------------------------------------------- | --------------------------------------------------------- |
| Pattern stats                  | [`pattern-stats.png`](pattern-stats.png)                   | built (`/stats`)                                          |
| Risk calculator                | [`risk-calculator.png`](risk-calculator.png)               | built (`/risk`)                                           |
| Alerts                         | [`alerts.png`](alerts.png)                                 | built (`/alerts`)                                         |
| Chart: detection settings      | [`chart-detection-config.png`](chart-detection-config.png) | built (`/chart`); v2 rule editing later                   |
| Chart: TradingView-style tools | [`chart-tradingview.png`](chart-tradingview.png)           | built (`/chart`): timeframes, indicators, panes, drawings |

Open questions for the owner are on the canvas as sticky notes (default sort, pre-filled account
size and risk, spot vs futures, alert channels, alerting on no-edge setups).
