How a study becomes a confirmation

  • 1Base rate (here): is the outcome different from a coin flip, with enough samples?
  • 2Strategy: add entry, stop, target and costs; backtest out-of-sample.P2
  • 3Forward test: paper-trade live; results must stay inside the backtest band.P4
  • 4Confirmation: news window clear, risk check passed, confidence calibrated.P6

Guards against fooling ourselves

  • ✓Minimum 30 independent events per study; overlapping events merged
  • ✓Wilson 95% range shown, never a bare percentage
  • ✓Every study counted toward multiple-testing correction (11 run so far)
  • !Costs ignored at this stage: base rates are not yet tradable edges
